題目:踩地雷

1.遊戲進行流程與規則:

遊戲目標：
找出所有沒有地雷的格子，並避開所有地雷。

遊戲規則：
棋盤由網格組成，部分格子藏有地雷。
翻開沒有地雷的格子，會顯示周圍 8 宮格內的地雷數量。
若翻開的格子周圍皆無地雷（顯示為 0），系統會自動展開相鄰的安全區域。
玩家可以對懷疑有地雷的格子「插旗」標記。

勝利條件：翻開所有非地雷的格子。

失敗條件：翻開任何一顆地雷。


2.內容操作說明:

遊戲採命令列（Console / Terminal）文字介面互動。
輸入格式：[動作] [X座標] [Y座標]
動作指令：
r (Reveal)：翻開格子。例如 r 3 4 代表翻開座標 (3,4) 的格子。
f (Flag)：插旗 / 拔旗。例如 f 3 4 代表在 (3,4) 標記地雷。
q (Quit)：中途退出遊戲。

3.程式如何安裝執行:

步驟一：打開命令提示字元，使用 cd 指令進入程式碼所在資料夾。

步驟二（編譯）：輸入以下指令將原始碼打包成執行檔：
g++ main.cpp Game.cpp Board.cpp Cell.cpp -o Minesweeper

步驟三（啟動）：編譯完成後，輸入執行指令即可開始遊戲：
.\Minesweeper.exe
